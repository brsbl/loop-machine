# components/

React components for the loop machine UI.

- `Sequencer.jsx` - Main sequencer grid with tracks and transport
- `DrumMachine.jsx` - Drum machine container
- `Track.jsx` / `TrackControls.jsx` - Individual track row and controls
- `TransportControls.jsx` - Play/stop, BPM, volume controls
- `Keyboard.jsx` / `Key.jsx` - Synth keyboard
- `KeyboardControls.jsx` - Synth parameters (filter, envelope, effects)
- `AudioVisualizer.jsx` - Waveform/frequency display
- `ui/` - Reusable UI primitives (Button, Knob, Fader)
