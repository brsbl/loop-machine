# Contributing

Thanks for your interest in contributing to Loop Machine!

## How to Contribute

- **Bug reports**: [Open an issue](https://github.com/brsbl/loop-machine/issues/new) with steps to reproduce
- **Feature requests**: [Open an issue](https://github.com/brsbl/loop-machine/issues/new) describing the feature and use case

## Development Setup

```bash
git clone https://github.com/brsbl/loop-machine.git
cd loop-machine
npm install
npm run dev
```

## Before Submitting a PR

```bash
npm run lint
npm test
npm run build
```

All checks must pass before merging.
